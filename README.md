# Python-fullstack-core-
Demonstration of high-level proficiency in the Python programming language.

### Python Assignment 1 - python-fundamentals-core
Basics: Variables, Calculations, Indexing and Formatting

### Objective
This introductory Python project demonstrates the foundational principles of programming: storing values in variables, performing mathematical computations, and clean output rendering using modern string formatting techniques. It serves as a clear guide for setting up data structures, executing arithmetic, and generating human-readable outputs.

### Key Features
* **Dynamic Variables:** Storing and organizing multiple data types (integers, floats, and strings).
* **Mathematical Operations:** Executing standard arithmetic routines including addition, multiplication, division, and exponents.
* **Sequence Indexing & Slicing:** Extracting individual characters or segments from strings and items from lists using zero-based positive and negative indexing.
* **Output Formatting:** Implementing Python f-strings to display numerical values .
 
### Tools & Environment 
* **Language:** Python 3
* **Environment:** Run via  Jupyter Notebooks.
